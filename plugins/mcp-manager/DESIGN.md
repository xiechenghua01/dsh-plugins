# MCP 服务管理 — 交互与 UI 设计规格

本文档是 `client.js` 的 UI 契约，供开发（Claude Code）与审核（Codex）共同使用。所有条目都是
可验收的硬性要求；「不跳动」「固定尺寸」「一致」是最高优先级。

## 0. 设计原则

1. **零布局跳动**：任何交互（切换标签、展开浮层、多选、勾选、加载状态变化）都不得改变
   对话框外框尺寸，也不得改变页面其他区域的位置。
2. **固定尺寸**：每个对话框有固定的宽高，内容超出时只有内容区滚动。
3. **一致性**：所有对话框共享同一套结构（标题栏 / 可选设置行 / 标签行 / 内容区 / 底部操作栏）
   和同一套尺寸与间距 token。
4. **作用域优先**：作用域与工作目录是对话框级设置，位于标签行之上，与当前标签无关。

## 1. 对话框统一规范

所有对话框（新增/编辑、JSON 查看、库添加、删除确认）都遵循：

```
┌──────────────────────────────────────────────┐
│ 标题                                        × │  标题栏：固定高度 48px
├──────────────────────────────────────────────┤
│ 设置行（可选，如作用域 + 工作目录）           │  固定高度 44px，单行，不换行
├──────────────────────────────────────────────┤
│ 标签行（可选，如 结构化 | JSON）              │  固定高度 40px
├──────────────────────────────────────────────┤
│                                              │
│ 内容区（flex:1，overflow:auto）               │  唯一可滚动区域
│                                              │
├──────────────────────────────────────────────┤
│ [左操作]                        [取消] [保存] │  底部栏：固定高度 56px
└──────────────────────────────────────────────┘
```

- 外框宽度：`width: min(680px, calc(100vw - 48px))`；确认类小对话框可用
  `min(440px, calc(100vw - 48px))`，但同类对话框之间必须一致。
- 外框高度：`height: min(720px, calc(86vh))`；确认类小对话框 `auto` 但最小高度固定
  （`min-height: 200px`），且同类一致。
- 编辑器对话框的宽高**必须固定**：`height: min(720px, 86vh)`，不因标签切换、内容多少、
  错误提示出现而改变。
- 外框：`display:flex; flex-direction:column; overflow:hidden`。
- 背景遮罩：透明（`background: transparent`），只用于捕获外部点击关闭，不得压暗设置面板。
- 对话框自身：`background: var(--dsw-alias-bg-layer-1)`、`border: 1px solid
  var(--dsw-alias-border-l2)`、`box-shadow`（用 token）、`border-radius: var(--dsw-radius-sm)`。

## 2. 编辑器对话框（新增 / 编辑）

结构从上到下：

1. **标题栏**：`新增 MCP 服务器` / `编辑 MCP 服务器`，右侧关闭按钮。
2. **设置行（在标签之上，固定单行）**：
   - 左：`作用域` 标签 + 分段控件 `全局 | 工作区`。
   - 右：`工作目录` 标签 + 多选按钮 + 已选 chips。
   - 该行高度固定；任何内容不得换行撑高。
3. **标签行**：`结构化 | JSON`。
4. **内容区**：`flex:1; min-height:0; overflow:auto`，内部按标签渲染表单或 JSON 编辑器。
5. **底部栏**：左侧 `测试连接`，右侧 `取消` `保存`。

### 2.1 作用域

- **新增时默认「全局」**（`level: 'global'`）。
- 编辑时显示该行的实际作用域，且**锁定**（分段控件禁用，附 tooltip 说明作用域由行位置决定，
  不能在此切换）。
- 作用域与标签无关：无论当前是「结构化」还是「JSON」，设置行始终显示且可操作。

### 2.2 工作目录多选（仅作用域 = 工作区时显示）

- 控件：`工作目录` 标签 + 按钮（未选时「选择工作目录」，已选时「已选 N 个目录」）+ chips。
- **固定位置与固定高度**：
  - 整个设置行单行布局，`flex-wrap: nowrap`；
  - chips 容器 `display:flex; flex-wrap:nowrap; overflow-x:auto; min-width:0`，**永不换行**；
  - 设置行高度固定（44px），chips 溢出时横向滚动，不得把行撑高、不得把页面内容顶下去。
- 浮层：绝对定位（`position:absolute`）在按钮下方，不参与布局流，打开/关闭不改变任何尺寸。
- 浮层内容：全选 / 清空 / 工作区 checkbox 列表（title，空则路径末段）；无工作区时「暂无工作区」。
- 作用域切到「全局」时工作目录控件隐藏（`display:none`），但已选值保留在 draft 中；切回
  「工作区」时恢复显示与已选 chips。隐藏/显示**不得**改变对话框尺寸（设置行高度固定）。
- 提交：create/update 传 `workspaces: string[]`（全局时传 `[]`）。

### 2.3 表单与 JSON

- 表单区不得因为错误提示、测试结果、字段显隐（stdio ↔ streamable-http 切换）而撑大对话框；
  内容超出时由内容区滚动。
- JSON 标签页：等宽字体 textarea 填满内容区（`flex:1; min-height:0`），不得让对话框缩小或放大。
- 切换标签时对话框外框尺寸不变；标签行位置不变。
- 错误/提示信息显示在内容区内的固定位置（表单底部或顶部提示条），不得推动底部栏。

## 3. 其他对话框的一致性

- **JSON 查看**：标题栏 + 内容区（等宽 JSON，滚动）+ 底部（复制/关闭）；与编辑器同宽。
- **库添加**：标题栏 + 内容区（目标作用域、名称、可选工作目录）+ 底部（取消/新增）。
- **删除确认**：小尺寸固定宽度、`min-height` 固定，底部「取消 / 确认删除」。
- 所有对话框：Escape 关闭、点击遮罩空白处关闭、焦点还原到触发按钮；关闭不改变页面滚动位置。

## 4. 列表页稳定性

- 作用域筛选（全部/全局/工作区）、搜索、刷新、测试全部：不得让列表区域跳动。
- 卡片内新增/删除 chip（工作目录、探测结果、错误提示）不得改变卡片高度以外的布局；
  探测结果区域固定最小高度，未测试/测试中/成功/失败之间切换不改变卡片高度。
- 导入/导出区、服务器库区：按钮与输入框位置固定，导入结果提示出现时不推动下方内容
  （使用固定高度提示条或预留空间）。

## 5. 样式与工程约束（不变）

- 仅 `require('react')`；无 `@deepseek-ai/`、无绝对 home 路径。
- 样式只用 `--dsw-*` token，class 前缀 `mm-`；不写字面色值。
- 内联 `const zh = {` / `const en = {` 字典：单引号、每行一个键、zh/en 键集一致、值非空、
  每个键在字典外被 `t('key')` 引用。
- `apply(ctx)` 内注入并清理 `<style>`；不新增全局副作用。

## 6. 验收清单（审核逐条核对）

- [ ] 新增对话框默认作用域为「全局」。
- [ ] 作用域 + 工作目录行位于「结构化 | JSON」标签之上。
- [ ] 切换「结构化 ↔ JSON」时，对话框宽度、高度、位置完全不变。
- [ ] 工作目录选中 0/1/3/全部时，设置行高度不变，chips 单行横向滚动，页面不跳动。
- [ ] 工作目录浮层打开/关闭不改变任何布局尺寸。
- [ ] 作用域切到全局时，工作目录控件隐藏但对话框尺寸不变；切回工作区恢复已选。
- [ ] 编辑已有行时作用域锁定且显示正确。
- [ ] 表单校验错误、测试连接结果出现时，对话框尺寸不变。
- [ ] JSON 查看、库添加、删除确认三个对话框与编辑器使用同一套标题/底部规范与尺寸策略。
- [ ] 嵌套对话框按 Escape **只关闭最上层**（例如删除确认 → 只关确认框，设置面板保持打开），
      点击遮罩关闭同理。
- [ ] 列表页筛选、搜索、探测结果变化不引起页面跳动。
- [ ] 无字面色值、无 `@deepseek-ai/`、字典键集一致且全部被引用。
