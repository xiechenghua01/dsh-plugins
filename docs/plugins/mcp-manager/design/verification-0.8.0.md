### 真实 CSS 回退测试

这是故障注入，不是正常产品操作：临时移除所属宿主的 `role`，触发已有 resize 监听，让 Dialog 真正走无宿主路径；测试后恢复该属性与视口。

- 正常视口：`mode=cover-host`、无测量标记、无行内 width，实际 CSS 宽度 640px，max-height=805px。
- 500×500 视口：实际窗口宽 468、高 404、left=16、right=484。
- 恢复宿主后：重新出现测量标记，恢复 800×800。
- 未在测试代码中复制一套 CSS 尺寸算法代替上述浏览器计算值。

标准模式不测量宿主、确认强制 standard、ResizeObserver/resize/scroll 的更新与卸载清理、偏移/非有限/断连宿主等边界，另由 [UI 合成测试](<../../../../plugins/mcp-manager/tests/ui-contract.mjs>)覆盖。
