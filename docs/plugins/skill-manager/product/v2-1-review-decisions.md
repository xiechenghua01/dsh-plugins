## 2. 二级 Tab（替代折叠分组）

技能 Tab 内部再放一行 Tab，与一级 Tab 同一套视觉：

| 顺序 | Tab | 计数 | 空态 |
| --- | --- | --- | --- |
| 1 | 我的技能 | 数字徽章 | 「还没有自己的技能，从市场装一个或新建一个」 |
| 2 | 共享技能 | 数字徽章 | 「这里放所有 Agent 共用的技能」 |
| 3 | 项目技能 | 数字徽章 | 「当前项目还没有技能」 |
| 4 | 系统内置 | 数字徽章 | 「Harness 自带的技能都正常」 |

规则：

- **一屏只显示一个分类**，不再有可折叠的分组头，也不再显示分组副标题（副标题的信息并入空态与详情）。
- 二级 Tab 记忆上次选择；默认 `我的技能`。
- 分类计数来自列表总数，与筛选无关。
- 搜索时**跨分类搜索**，命中后自动切到第一个有结果的分类，并保持搜索词；搜索结果在分类内展示。
- 分类为空时整屏显示空态，不给「切到别的分类」以外的干扰。
- 二级 Tab 只在技能 Tab 出现；市场 Tab 没有二级 Tab。

> 与 v2.0 的差异：v2.0 的「默认展开前三组、系统内置折叠」规则作废。

## 3. 两列卡片

技能页与市场页**都改成两列卡片**。

### 3.1 网格

- `grid-template-columns: repeat(2, minmax(0, 1fr))`，`gap: 12px`。
- 内容区宽度 ≤ 720px 时退化为单列。
- 参考 DSH Discover 的实测值：其卡片网格为 `repeat(auto-fill, minmax(268px, 1fr))`、`gap: 12px`；本模块按评审要求固定两列，最小卡宽 268px 作为**单列退化阈值**的依据。

### 3.2 卡片结构

```
┌─────────────────────────────────────────────┐
│ ┌────┐  名称  [徽章]                  ┌───┐ │
│ │图标│  一行描述（最多 2 行）          │ ▸ │ │
│ └────┘                                 └───┘ │
└─────────────────────────────────────────────┘
        右侧竖排：唯一按钮 + ⋯
```

- 左侧：48×48 图标容器（DSH 实测 `48×48`、`border: .5px`、`border-radius: radius-lg`）、名称、一行描述。
- 右侧：**竖排两个控件**——唯一主按钮（`更新` / `安装` / `已安装`）在上，`⋯` 菜单在下；无写操作时只留 `⋯`。
- 卡片整体可点击进详情；右侧按钮与菜单阻止冒泡。
- 卡片样式对齐 DSH Discover 卡片：`border: .5px solid var(--dsw-alias-settings-card-stroke)`、`border-radius: var(--dsw-radius-xl)`、`background: var(--dsw-alias-settings-card-fill)`。
- 卡片高度统一（约 96px），描述最多 2 行，超出省略。

### 3.3 已停用

- 卡片整体降对比（`opacity: .6`），名称前不加额外标签；「已停用」徽章保留。

## 4. 市场按源分组

- 市场 Tab **不设二级 Tab**，改为按市场源分区块：

```
chengze-skills                    12 个技能   [⋯]
┌──────────┐ ┌──────────┐
│ 卡片      │ │ 卡片      │
└──────────┘ └──────────┘
┌──────────┐ ┌──────────┐
...
```

- 每个源一个区块标题：源名称、技能数、该源的 `⋯`（刷新 / 删除 / 上移 / 下移）。
- 「全部源」不提供合并视图；不提供源筛选——顺序即优先级。
- 无源时整页空态「添加一个技能索引源」。

### 4.1 源排序

- 管理源抽屉里每个源可**上移 / 下移**（拖拽为可选增强，先做按钮）。
- 排序即优先级：**排在前面的源，其技能在市场中排在前面，同名技能也以它为准**。
- 该顺序同样用于「已安装」列表中按来源排序时的先后。
- 排序持久化在本地状态里，重启后保留。
- 新增源默认排最后。

## 5. 状态图标（替代两条横幅）

- 位置：**Tab 栏右侧**，与「技能 / 市场」同一行，右对齐。
- 两个图标，只有图标没有文字：

| 图标 | 含义 | 出现条件 | 悬停提示（300ms） | 点击 |
| --- | --- | --- | --- | --- |
| 警示（三角） | 有技能未生效 | 未生效数量 > 0 | `{n} 个技能未生效` | 打开诊断抽屉 |
| 向上箭头（带点） | 有技能可更新 | 可更新数量 > 0 | `{n} 个技能可以更新 · 上次检查 {when}` | 触发更新流程 |

- 图标尺寸 16px，热区 32×32，颜色：警示用 `--dsw-alias-state-warn-primary`，更新用 `--dsw-alias-state-business-primary`。
- 数量为 0 时不显示图标。
- **删除** v2.0 的顶部警示条与更新细条；详情页内的更新按钮仍然保留。

## 6. 弹窗尺寸（对齐 DSH 实测值）

| 弹窗 | 宽度 | 依据 |
| --- | --- | --- |
| 新建技能、导入技能、添加源 | `min(488px, 100%)` | DSH 表单弹窗实测 `GSsNcq_dialog` |
| 更新确认、卸载确认、删除确认 | `min(480px, 100vw - 32px)` | DSH 确认弹窗实测 `nLFHAG_dialog` |
| 编辑原文、SKILL.md 预览 | `min(720px, 100%)` | DSH 大内容弹窗实测 `gdzZCG_dialog` |

补充规格（DSH 实测）：

- 圆角 `var(--dsw-radius-panel)`（表单）/ `var(--dsw-radius-xl)`（确认）。
- 边框 `border: .5px solid var(--dsw-alias-border-inverted)`。
- 表单弹窗内部 `gap: 38px`（标题区与表单区）。
- 确认框正文 `gap: 12px`。
- 底部按钮右对齐区高度约 56px，主按钮在右。
- 不再使用 v2.0 的 560px / 640px 自定宽度。

## 8. 验收口径（v2.1 新增）

1. 打开任意分类，一屏只有该分类的技能，没有折叠分组头。
2. 任意窗口宽度 ≥ 1280 时，技能页与市场页均为两列卡片，卡片右侧竖排操作。
3. Tab 栏右侧最多出现两个图标；未生效与有更新都为 0 时该区域为空。
4. 弹窗宽度不超过 488px（表单）或 480px（确认），与 DSH 其它弹窗并排时不显得突兀。
5. 市场按源分区块，调整源顺序后市场区块顺序与「按来源」排序同步变化。
