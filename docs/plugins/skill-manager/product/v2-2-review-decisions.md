## 2. 技能页：Tab 内再按来源分组

保留四个二级 Tab（我的技能 / 共享技能 / 项目技能 / 系统内置），每个 Tab 内部再按**来源**分组：

| 分组 | 判定 | 组头 |
| --- | --- | --- |
| 市场源 A | 安装记录里 `sourceId` 属于该源 | 源名称 + `N 个技能` |
| 市场源 B | 同上 | 同上 |
| 本地创建 | 没有 `sourceId`（手工新建、导入、手动放置） | `本地创建` + `N 个技能` |

规则：

- 组头顺序 = 源顺序（同市场页），「本地创建」固定排在最后。
- 空组不渲染。
- 组头不可折叠（保持简单），组内是两列卡片。
- 系统内置 Tab 不按来源分组（它们全部来自 Harness 本身）。
- 搜索仍跨分类；分组随之过滤，命中为空的分组不渲染。

> 与 v2.1 的差异：v2.1 每个 Tab 内是一整片两列卡片，现在再插入来源分组层级。

## 3. 工具栏：图标化

`技能` Tab 的工具栏改为：搜索框 · 排序下拉 · 三个图标按钮。

| 控件 | 形态 | 悬停提示 | 点击 |
| --- | --- | --- | --- |
| 新建技能 | 30×30 图标按钮 | `新建技能` | 打开新建弹窗 |
| 导入技能 | 30×30 图标按钮 | `导入技能` | 打开导入弹窗 |
| 检查更新 | 30×30 图标按钮 | `检查更新` | 检查所有源的更新并刷新列表 |

- **删除** 工具栏 `⋯` 菜单。
- **合并**「检查更新」与「刷新列表」：只保留一个动作，它既检查更新也重新拉取列表；执行时按钮转圈，完成后 toast 汇总（`已检查 N 个源，M 个技能可更新`）。
- 排序下拉保留（名称 / 最近修改 / 按来源）。
- 按钮之间的间距 6px；图标 16px。

市场 Tab 工具栏：搜索 · 排序 · `管理源` 图标按钮（同样图标化 + 提示 `管理源`）。

## 4. 卡片右侧操作

### 4.1 布局

```
                        ┌───┐ ┌──────┐
                        │ ⋯ │ │ 更新 │
                        └───┘ └──────┘
```

- `⋯` 在左、主按钮在右，**同一行**、水平排列、右对齐。
- 无主按钮时只显示 `⋯`，仍在右侧同一位置。

### 4.2 可见性

- `⋯` 默认 `opacity: 0`，不占位移（保留占位，避免布局跳动）。
- 卡片 `:hover`、`:focus-within` 时 `⋯` 淡入（120ms）。
- 键盘 `Tab` 聚焦到 `⋯` 时也显示（`:focus-visible`）。
- 主按钮始终可见（有更新/可安装时）。

### 4.3 市场卡片

同样规则：`⋯` 在「安装 / 更新 / 已安装」左侧，默认隐藏，hover 显示。

## 5. 管理源：抽屉改弹窗 + 拖动排序

### 5.1 形态

- 由右侧抽屉改为**居中弹窗**。
- 宽度：`min(720px, 100vw - 32px)`。依据 DSH 实测：大内容弹窗为 `min(720px, 100%)`，确认框为 `min(480px, 100vw - 32px)`；管理源列表内容多，取大弹窗档并强制视口余量 32px，保证 1280 / 1024 / 800 宽下都不溢出。
- 圆角 `var(--dsw-radius-panel)`、边框 `.5px`、无阴影。
- 最大高度 `min(720px, 100vh - 96px)`，列表区内部滚动。

### 5.2 结构

1. 标题「管理源」+ 计数徽章 + 关闭。
2. 说明：`排序即优先级：排在前面的源，其技能在市场中排在前面。`
3. 源列表：每行可拖动，行内包含拖动手柄、状态点、名称、技能数、启用开关、刷新、删除。
4. 「添加索引源…」按钮 + 说明。

### 5.3 排序

- **拖动排序**：整行 `draggable="true"`，拖动时显示插入位置指示线，放下后立即重排并持久化。
- 移除上移 / 下移箭头按钮。
- 键盘替代：行获得焦点后 `Alt+↑` / `Alt+↓` 移动（可访问性兜底）。
- 拖动把手在行首，尺寸 16×16，光标 `grab` / `grabbing`。

## 6. 修复记录

**tooltip 不显示**：原型里元素是 `<div id="tooltip">`，而 CSS 选择器写成了 `#sm-tooltip`，样式全部未命中，提示语虽渲染但无定位与背景，实际不可见。已统一为 `#tooltip`，并用真实浏览器验证：悬停警示图标 300ms 后出现「1 个技能未生效」，`position: fixed`、背景 `rgb(44,44,46)`、opacity 1。

## 7. 验收口径（v2.2 新增）

1. 技能页任意二级 Tab 内，卡片按来源分组，组头顺序与市场页一致，「本地创建」在最后。
2. 工具栏只有搜索、排序与三个图标按钮；不存在 `⋯` 菜单，也不存在单独的「刷新列表」。
3. 悬停任意图标或状态点，300ms 后出现提示语。
4. 卡片右侧是水平排列的 `⋯` 与主按钮；未悬停时看不到 `⋯`，悬停后出现且不引起布局位移。
5. 管理源是居中弹窗，宽度不超过 720px 且在任何窗口下留 32px 边距；只支持拖动排序，没有上下箭头。
