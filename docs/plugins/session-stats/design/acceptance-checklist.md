# session-stats 入口与密度整改验收清单

## 范围

只验 UI 层：侧栏入口的位置与字号、面板字号层级、信息密度。不验数据层（payload、预算、归档、日志读取），不扩展到其他插件。

## 需求

### A. 侧栏入口

1. 从 `sidebar.footer.action` 迁移到 `sidebar.panellist`（id `session-stats`，order 30），渲染位置在「技能」下方、「更多」之前。
2. 组件只渲染图标：16×16；宿主传入 18（折叠态）时按 18 渲染。图标之外不渲染按钮、文字或行背景。
3. 入口文字、整行按钮、字号由宿主渲染，必须与「技能」入口一致。
4. 保留「面板已打开时再次点击关闭，返回 Conversation」。

### B. 面板字号

基准 16px 时，实测目标：

| 元素 | 选择器 | 目标 |
| --- | --- | --- |
| 页面标题 | `.ss-title` | 18px（fs+2） |
| 区块标题 | `.ss-card-title` | 16px（fs） |
| 摘要数值 | `.ss-summary-value` | 18px（fs+2） |
| 摘要标签/提示 | `.ss-summary-label` / `.ss-summary-hint` | 13px（fs−3） |
| 表格正文 | `.ss-table` | 15px（fs−1） |
| 表头 | `.ss-table th` | 13px（fs−3） |
| 轴标签 | `.ss-yaxis` / `.ss-xaxis` | 13px（fs−3） |

字号仍必须由 `--ds-fs` 派生，不新增第二套字号变量，不写裸 px 字号。

### C. 信息密度

1. 区块间距 24px（`.ss-sections` gap）；摘要 grid gap 16px。
2. 模型用量默认 5 行，底部「查看更多」每次 +5；展开后全部行。
3. 会话表移除独立的「输入 / 输出 / 缓存」列，改为 Token 数值下方的小字（保留输入/输出/缓存信息）；列数由 7 变为 6。
4. 不得裁切、重叠或出现横向滚动；20px 字号下仍可用。

### D. 主题与字号

浅色、深色都清晰；宿主字号 12/16/20 都跟随且不破版。

## 证据要求

每条结论给选择器或 `文件:行号`；字号、列数、行数、入口顺序必须给实测值。

## 收敛

默认 3 轮内通过；无 P0/P1 问题即收敛。
